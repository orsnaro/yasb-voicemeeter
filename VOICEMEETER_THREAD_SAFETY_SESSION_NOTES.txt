Key findings
1) Wrong stopped check can start event infra incorrectly
- In VoicemeeterInterface.RegisterControlChangeNotify, code checks `if self.vm_direct.stopped:`.
- In voicemeeterlib, `stopped` is a method (`stopped()`).
- This mismatch can cause incorrect thread start behavior and repeated starts.

2) Observer/event mutation without synchronization
- Interface adds/removes observers/events while updater thread may iterate observers and notify.
- voicemeeterlib Subject has no lock around add/remove/notify.
- This creates race potential.

3) Thread lifecycle handling is inconsistent
- Unregister joins locally created launcher threads but does not consistently use vm_direct.end_thread() for lifecycle.
- Correct shutdown path in wrapper is end_thread() + logout().

4) UI thread safety path is mostly correct in AudioOutputService
- on_notify emits Qt signal; service slot updates widgets via signal dispatch.
- This is good and should be retained.

Step 2: Single-owner model example
- Put all vm_direct calls inside one QObject living in one QThread.

```python
# src/core/utils/widgets/voicemeeter/vm_worker.py
from PyQt6.QtCore import QObject, QThread, pyqtSignal, pyqtSlot
import voicemeeterlib

class VmWorker(QObject):
    changed = pyqtSignal()
    error = pyqtSignal(str)

    def __init__(self, kind="banana"):
        super().__init__()
        self.vm = voicemeeterlib.api(kind, sync=True)
        self._started = False

    @pyqtSlot()
    def start(self):
        try:
            self.vm.login()
            if self.vm.stopped():
                self.vm.init_thread()
            self.vm.event.add(["pdirty"])
            self.vm.observer.add(self)
            self._started = True
        except Exception as e:
            self.error.emit(str(e))

    @pyqtSlot()
    def stop(self):
        try:
            if self._started:
                self.vm.observer.remove(self)
                self.vm.event.remove(["pdirty"])
                self.vm.end_thread()
                self.vm.logout()
                self._started = False
        except Exception as e:
            self.error.emit(str(e))

    def on_update(self, event):
        if event == "pdirty":
            self.changed.emit()
```

Service wiring:

```python
self._thread = QThread()
self._worker = VmWorker()
self._worker.moveToThread(self._thread)
self._thread.started.connect(self._worker.start)
self._thread.start()
```

Step 3: Lock shared state example
- Protect class/global mutable state with a single RLock.

```python
import threading

class VoicemeeterInterface:
    _state_lock = threading.RLock()
    _instances_count = 0
    _watched_instances = {}
    _subscribers = 0

    def __new__(cls, **kwargs):
        with cls._state_lock:
            cls._instances_count += 1
        return super().__new__(cls)

    def __del__(self):
        with self.__class__._state_lock:
            self.__class__._instances_count -= 1
```

Step 4: Refcount lifecycle example
- First subscriber starts events; last subscriber stops events.

```python
def RegisterControlChangeNotify(self, callback):
    with self.__class__._state_lock:
        self._shared_volume_callback = callback
        self.vm_direct.observer.add(self)
        self.__class__._subscribers += 1
        if self.__class__._subscribers == 1:
            self.vm_direct.clear_dirty()
            if self.vm_direct.stopped():
                self.vm_direct.init_thread()
            self.vm_direct.event.add(["pdirty"])

def UnregisterControlChangeNotify(self, callback):
    with self.__class__._state_lock:
        self.vm_direct.observer.remove(self)
        self._shared_volume_callback = None
        self.__class__._subscribers = max(0, self.__class__._subscribers - 1)
        if self.__class__._subscribers == 0:
            self.vm_direct.event.remove(["pdirty"])
            self.vm_direct.end_thread()
```

Step 5: Keep UI updates on Qt thread
- Use signal bridge from callback thread to Qt slot.

```python
class AudioOutputService(QObject):
    volume_change_requested = pyqtSignal()

    def __init__(self):
        ...
        self.volume_change_requested.connect(self._on_volume_change)

class _SharedVolumeCallback(AudioEndpointVolumeCallback):
    def on_notify(self, *_):
        self.service.volume_change_requested.emit()
```

For worker model:

```python
self._worker.changed.connect(self._on_volume_change)  # queued cross-thread
```

Suggested implementation order
1) Hotfix: `if self.vm_direct.stopped:` -> `if self.vm_direct.stopped():`.
2) Add refcount + lock in current interface.
3) Then migrate to full single-owner worker design.
